# 最近密码库、导入与扩展使用教程

[English](USAGE.en.md) · 简体中文

## 最近密码库

在网页或扩展选择 `.db` 并成功解锁，或验证保存文件后，最近密码库会保留最多 5 个记录。只保存文件名称、句柄、记录 ID、时间及你确认的目录文字标记，不保存主密码、条目或密码库内容。网页与扩展的记录按浏览器来源隔离。

网页首页和偏好设置、扩展锁定页均提供记录入口。点击记录后允许浏览器访问，再输入主密码。权限过期可重新授权；文件移动或删除时重新选择文件。普通文件输入不提供可复用句柄，记录会标明“需要重新选择文件”。禁用存储或隐私模式不支持持久化时，提示记录仅在当前页面有效。

浏览器不会提供完整的本地绝对路径。支持目录选择且记录带有文件句柄时，可点击记录旁的文件夹图标“确认所在目录”，选择包含该密码库的文件夹（只读授权）。应用核对文件确实位于所选目录下，再显示“上次确认的目录”，例如 `Documents/Passwords`：`Documents` 为所选文件夹名，`Passwords` 为其下的相对目录。选错目录会提示重选，取消不会更改记录。目录句柄不会保存，也不会读取该目录其他文件。文件移动后请重新确认；该标记只代表上次确认的位置，不代表实时绝对路径。普通文件输入或不支持目录选择时，请在系统文件窗口中核对。

用移除按钮删除单条，或点击“清空记录”。操作仅删除浏览器中的入口，不删除磁盘文件。最近记录不是备份，也不会保存尚未写入文件的修改。

## 从 Chrome / Bitwarden 导入

1. Chrome：打开 Google 密码管理工具的设置，选择导出密码并完成系统身份验证，保存 CSV。Bitwarden：导出为未加密 CSV 或 JSON；多个网址和带类型的自定义字段优先选择 JSON。参考 [Chrome 官方导出说明](https://support.google.com/chrome/answer/13068232) 与 [Bitwarden 文件结构](https://bitwarden.com/help/condition-bitwarden-import/)。
2. 在网页打开或新建目标密码库并解锁。扩展先打开已有 `.db` 并解锁。点击顶栏、偏好设置或扩展中的“导入密码”。
3. 选择来源格式和原始导出文件，再点击“预览导入”。单文件最多 20 MB、10000 条。预览显示新增、重复、不支持的数量及前 10 个名称和账号，不显示密码。
4. 核对字段映射：名称 → 条目名称；用户名 → 账号；密码 → 密码；网址 → 网站；文件夹 → 标签；备注和收藏保留。完全相同的条目跳过，内容或密码不同则分别保留，不覆盖已有条目。
5. 确认导入后点击“保存数据库”。第一次覆盖前选择独立加密备份目录。出现“已验证保存”后重新打开 `.db` 核对；普通下载只能确认已发起导出，须自行确认文件落盘。确认加密保存和数据完整后，再妥善清理包含明文密码的源文件。

支持 Bitwarden 登录和安全笔记。JSON 保留多个网址、文本/布尔/隐藏自定义字段；CSV 自定义字段整体保留为私密字段。不支持的 TOTP 密钥原样保留为私密字段。卡片、身份等类型计数跳过，附件、通行密钥和关联字段显示未导入提示。Bitwarden 的网址匹配规则及再次验证策略不迁移；扩展始终按精确 HTTPS 来源匹配。请保留原工具数据直到完成核对。

取消、Esc、锁定或完成导入均清除预览引用。导入不自动保存，也不会上传源文件。

## 扩展填充与多网址

安装说明见 [自托管教程](SELF-HOSTING.md)。更新后在扩展管理页重新加载扩展，重新打开侧栏。

1. 打开目标 HTTPS 网站，点击工具栏扩展图标授权，再选择文件或最近密码库，输入主密码。
2. 核对网站和账号，点击“填充此账号”。扩展不提交表单。用户名与密码分步的网站，第一步只填唯一且明确的用户名/邮箱框；在网站继续到密码页后再点击填充。跳到其他来源时重新点击扩展图标授权。
3. 同一账号用于多个网址时，在新网站授权后点击“添加网站地址”，核对来源并选择条目，确认后保存。网页编辑器也提供“添加网站地址”，会增加一个网站字段。域名、子域和端口都按各自精确来源匹配，不自动扩大范围。
4. “查看所有条目”便于修改非当前站点条目，不匹配网站的填充按钮保持禁用。多个密码框、验证码框、新密码表单和 iframe 不会自动填充。

## 扩展更新密码

在网站修改密码时，对应条目点击“更新密码”。手动输入新密码两次，或明确点击“从当前网页读取新密码”：仅读取当前匹配 HTTPS 网站可见且标记为 `new-password` 的密码框；两个确认框须内容一致，无法识别时手动输入。读取结果只放入扩展确认表单，不会立即修改条目。一个条目含多个密码字段时，先选择要更新的字段。

核对条目和新密码，确认网站修改成功，再确认更新和“保存数据库”。扩展不监听网站输入和提交，不自动采集密码。更新和导入后，未保存提示会持续显示。

## 保存、冲突和锁定

网页和扩展共用写回逻辑：原文件 SHA-256 检查 → 备份原始密文并校验 → 再次检查源文件 → 写入 → 读回校验。首次覆盖选择独立加密备份目录；扩展默认保留当前页面当前文件最近 10 份备份。不会按同名删除其他会话备份。不支持文件写入时使用加密下载，并自行核对。

PWA 修改文件后，扩展会在下次填充时检查已关联文件的指纹。发现变化停止填充，先将当前未保存编辑“另存为 .db 文件”，再“重新加载文件”并输入主密码。重新加载有未保存修改时会要求明确确认放弃，取消不会丢弃内容。普通文件输入没有关联句柄，无法自动检测变化，需自行重新选择文件。不要同时在两个应用中编辑同一库。

侧栏隐藏或空闲会锁定，未保存内容加密暂存在当前侧栏内存。再次解锁可继续保存；关闭、刷新或重载扩展仍会丢失未保存内容。文件名和最近记录可能暴露使用痕迹，共用设备可清空记录；它们不会绕过主密码。
